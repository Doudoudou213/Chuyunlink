# 文化内容效果与智能体反馈闭环

第一版分四阶段：1 最小事件与匿名汇总；2 页面实际行为与投稿归因；3 管理员效果、版本比较与审核质量分栏；4 综合回归与边界验收。每阶段本地测试和 checkpoint，不部署，不操作生产数据。

事件只记录明确动作，不推断读完/真实到访/完整收听。不采集坐标、轨迹、设备指纹、IP、用户昵称或 UID。服务端仅保存按日/内容/版本汇总。临时内容级随机凭据最多有效12小时，仅用于去重和本次操作，不跨内容连接用户；下次后台读取或维护清理时分批物理移除。没有持续用户行为流水。过期凭据未上报关闭只能叫“超时未继续”，不能声称准确退出。

路线比较限定方式、时长档、站数档；不保存具体站点顺序或私人行程 ID。生成质量和使用效果分开，点击不能改变事实、模型或提示词。小样本只显示计数；至少20次打开、分子和剩余各不少于5时才显示相应比例，仍不宣称统计显著。

CONTENT_EFFECTS_ENABLED 默认关闭；页面或统计接口故障不影响原业务。第三方统计服务不需要。聚合集合只供管理员读取，用户接口只返回是否接收。生产集合权限与物理过期清理需要以后云端验收。

### 第一版能力边界

- 管理员“内容效果”入口可以筛选最近选定的连续最多7天，比较2至4个同类型内容版本、查看来源展开/继续探索/路线操作/贡献流转，并保存人工优化记录。
- 路线按出行方式、时长档、站数档比较，不区分精确站点序列；没有完整游客轨迹、独立访客数、自动推荐优胜模型或实验因果结论。
- 故事/专题的使用数据独立于审核；讲解可显示已有版本审核质量及模型/提示词/代码标记。其他内容审核仍复用原工作台，未强行转换成统一事实评分。
- 贡献仅统计本功能启用后、明确点击补充并成功关联的投稿；不回填旧投稿，不追踪跨设备。正式采用读取现有业务记录，附件补充不推断采用，不发新积分。
- 用户可在页面底部停用匿名效果统计；浏览器全局隐私控制也会停用。统计关闭或接口失败不应阻止原功能。公开客户端只收到是否接收，不返回聚合或用户身份。
- 退出上报可能丢失。12小时是随机凭据有效期，不是物理删除承诺；后台读取时每批清理最多100条过期凭据。实例内限频用于基础保护，不等同分布式防刷。
- 已有投稿本来就有所有者信息，归因仅增加聚合编号；统计集合不新增用户UID。人工优化记录的操作人仅保存在既有管理员审计中，不出现在效果报告。

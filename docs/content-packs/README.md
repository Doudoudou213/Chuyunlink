## 黄鹤楼

来源：[武汉市园林和林业局｜武汉市黄鹤楼公园管理处](https://ylj.wuhan.gov.cn/zwgk/zwxxgkzl_12298/jggk_12304/xsdwszjzz_12308/202001/t20200110_726398.shtml)；定位：单位简介。

### 可核对的事实候选

- **hhl-c1**：黄鹤楼位于武汉武昌蛇山。
- **hhl-c2**：黄鹤楼的始建年代为公元223年。
- **hhl-c3**：黄鹤楼公园于1985年6月重建开放。
- **hhl-c4**：黄鹤楼公园介绍将园区分为东、北、南、西四区。
- **hhl-c5**：黄鹤楼公园介绍将西区的游览内容集中于黄鹤楼文化，列有黄鹤楼与胜像宝塔。

### 通用参考稿

了解黄鹤楼，可以先分清两个时间：黄鹤楼始建于公元223年，公园重建开放则在1985年6月。〔hhl-c2、hhl-c3〕

地点在武汉武昌蛇山。园区分为四区，其中西区以黄鹤楼文化为主，包含主楼和胜像宝塔。〔hhl-c1、hhl-c4、hhl-c5〕

### 建筑参考稿

如果你关心建筑，先把始建与重建分开看：黄鹤楼的历史始于公元223年，公园于1985年6月重建开放。〔hhl-c2、hhl-c3〕

园区介绍在西区列出了黄鹤楼和胜像宝塔；这可以作为选看对象的线索，具体位置仍请核对现场导览。〔hhl-c5〕

### 现场观察与使用边界

到达后先按园区导览牌确认主楼及所在分区，再观察楼体；不提供未经现场核实的转弯和步数。

- 始建年代与重建开放时间分开，不称现楼是三国原楼。
- 官方地址不能直接当作游客入口。
- 同在武汉不代表三站能在半日内走完。

## 晴川阁

现有资源绑定候选：`qingchuan-pavilion`，尚未读取或写入云数据库。

来源：[武汉市文化和旅游局｜武汉市晴川阁管理处（武汉大禹文化博物馆）](https://wlj.wuhan.gov.cn/zfxxgk/fdzdgknr/jgjj/zsdw/202008/t20200827_1437251.shtml)；定位：单位介绍。

### 可核对的事实候选

- **qcg-c1**：晴川阁位于汉阳龟山东麓的长江边，与黄鹤楼隔江相望。
- **qcg-c2**：晴川阁景区于1986年10月正式开放。
- **qcg-c3**：晴川阁景区主要建筑包括禹稷行宫、晴川阁和铁门关。
- **qcg-c4**：晴川阁管理处于2010年8月加挂武汉大禹文化博物馆牌子。
- **qcg-c5**：武汉大禹文化博物馆介绍列有《水与城——武汉治水史迹展》基本陈列。
- **qcg-c6**：晴川阁景区包含古建筑与仿古建筑，不能将所有建筑视为同年代原物。

### 通用参考稿

晴川阁在汉阳龟山东麓的江边，与黄鹤楼隔江相望。这里的主要建筑包括禹稷行宫、晴川阁和铁门关。〔qcg-c1、qcg-c3〕

管理处还加挂武汉大禹文化博物馆牌子，馆方介绍列有武汉治水史迹相关陈列，可以沿着水与城市的主题继续了解。〔qcg-c4、qcg-c5〕

### 建筑参考稿

关注建筑时，可以分别认识禹稷行宫、晴川阁和铁门关。景区同时包含古建筑和仿古建筑，不能把它们全部当作同年代留下的原物。〔qcg-c3、qcg-c6〕

官方介绍中的1986年10月，是景区正式开放的时间，并不是这三座建筑共同的始建年代。〔qcg-c2、qcg-c3〕

### 现场观察与使用边界

根据现场标识辨认三座主要建筑，比较外观；当前材料不足以判断每一处构件的原建年代。

- 管理机构、景区和某栋建筑不能混为同一主体。
- 1986年开放不代表所有建筑始建于1986年。
- 大禹传说作为文化表达介绍，不自动当作已考证事件。

### 发布前还需核对

- 当天展览、入口与步行路径需现场或管理方复核。
- 不把隔江相望推导为历史传承、营造影响或直接步行可达。

- 核对事实与原文支持关系、当前来源有效性、公开使用范围；完成原有正式来源、事实、故事和讲解审核，不直接导入本包。
## 曾侯乙编钟

现有资源绑定候选：`hubei-museum`，尚未读取或写入云数据库。

来源：[湖北省博物馆｜曾侯乙编钟](https://www.hbww.org.cn/zgzb/p/4695.html)；定位：典藏／镇馆之宝／正文。本轮成功读取 www 页面；无 www 地址保留与既有隔离试跑适配器兼容，不代表本轮该地址连接通过。

### 可核对的事实候选

- **bells-c1**：曾侯乙编钟于1978年出土于湖北随州曾侯乙墓，属战国早期。
- **bells-c2**：曾侯乙编钟全套65件，按三层八组悬挂于曲尺形铜木钟架。
- **bells-c3**：曾侯乙编钟的钟、架和钩上铭文合计3755字，涉及编号、记事、标音和乐律理论。
- **bells-c4**：湖北省博物馆介绍指出，曾侯乙编钟每件钟可奏出呈三度音程的双音。

### 通用参考稿

曾侯乙编钟来自1978年发掘的湖北随州曾侯乙墓，年代属战国早期。全套65件，分三层八组悬挂在曲尺形钟架上。〔bells-c1、bells-c2〕

馆方介绍，每件钟能奏出呈三度音程的两个音。理解这套乐器，可以从排列和发音特点入手。〔bells-c4〕

### 碑刻参考稿

关注文字时，先分清铭文在哪里：馆方统计的3755字，合计来自钟、架和钩，不是单独一口钟。〔bells-c3〕

这些文字涉及编号、记事、标音和乐律理论，可以把它们看作理解这套乐器的线索。具体文字请以展签和释文为准。〔bells-c3〕

### 现场观察与使用边界

若对应展陈开放，可对照展签观察钟架的层次和排列；看不清铭文时阅读展签，不承诺可逐字辨认。

- 游览站点是湖北省博物馆，编钟是讲解对象，随州是出土地。
- 3755字是钟、架和钩的合计，不能写成每口钟或仅钟体字数。
- 不保证当天原件展出、铭文肉眼可读或有现场演奏。

### 发布前还需核对

- 展厅、原件展出状态、预约与当日演奏均需重新核对。
- 碑刻兴趣在本样本仅用于现有系统的铭文选材，不将青铜钟称为石碑。

- 核对事实与原文支持关系、当前来源有效性、公开使用范围；完成原有正式来源、事实、故事和讲解审核，不直接导入本包。

2. 核对叙述是否清楚、兴趣重点是否不同；实际读一遍，再填写适听和修改量。
3. 事实候选使用本地编号，不能替代数据库里的正式事实编号。经现有后台流程形成正式来源、确认事实和故事后，才进入线上讲解生成与审核。
4. 用户投稿仍需投稿人的有效授权；官网公开访问不等于用户授权或原文、图片可随意转载。
5. 不复制本包为已批准投稿，不自动发积分或生成贡献记录。
6. 模型试跑需要新的当次费用授权；原来的调用额度不重置。此包复用已有隔离试跑工具，工具只取事实候选，不读取这里的参考答案。

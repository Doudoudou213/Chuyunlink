## 修复

1. 首页及后台改用随站托管的固定版本 Tailwind；首页同时本地托管 Lucide、
   Leaflet 及地图控件图片。保留许可证和原版本，避免外部 CDN 故障阻断页面。
   首页图标装饰调用增加缺失保护，图标自身加载失败也不阻断初始化与切页。
   Tailwind 仍为浏览器运行时，没有冒称完成 CSS 预编译；地图瓦片、真实路线、
   CloudBase、可选网络字体仍需要联网。
2. 经纬度排除 null、空串、空白、布尔值、对象及越界值。缺地点不算距离，
   合法的数字 0 和字符串 '0' 保留；列表序列化与候选评分使用同一规则。
3. 后台列表读取使用当前页面与请求版本检查。跨栏目、同栏目重复刷新、
   迟到的错误均不能覆盖最新页面；相同模式覆盖评论、反馈、材料、故事、
   研究建议、专题及讲解等读取入口。
4. 撤回成功后刷新当前投稿列表，不再因为原卡片被另一次刷新移除而漏刷新。
   审核状态、奖励和授权规则不变。
5. 专题异步加载后恢复章节锚点，重新打开章节链接可定位到对应章节。
6. Logo 与楚凤原 PNG 保留，页面使用适合显示尺寸的 WebP：
   555,941 → 49,456 字节；1,640,403 → 34,162 字节。
   两者合计减少约 96%，不是整站加载耗时减少 96%。
7. 发布与 AI 初始化工作流均改为手动触发，仅允许统一的 doudoudou 分支；
   本地部署入口也检查该分支，并运行离线业务回归。
   本地工作流修改尚未上传，原 GitHub 仓库的远程配置没有被改变。
